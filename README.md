после добавления новой модели 
dbt 

schema.yaml внутри папки /models - и есть тесты 

* dbt debug — проверка подключения и конфига. Запускается редко: один раз при настройке, или когда что-то сломалось с доступом к базе. При добавлении модели он не нужен. Его задача — ответить «дбт вообще видит базу?».
* dbt run — строит модели (выполняет твои SELECT, создаёт view/таблицы в базе). Вот это ты запускаешь каждый раз, когда добавила или изменила модель. Без него новая модель существует только файлом, а в базе её нет.
* dbt test — прогоняет проверки данных из schema.yml. Запускаешь после run, чтобы убедиться, что данные корректны.
